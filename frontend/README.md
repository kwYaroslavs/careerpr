# CareerPR Frontend Workspace

Simple workspace frontend for CareerPR supporting manual profile/fact entry and verification/evidence display, interacting with FastAPI backend (`backend/app/main.py`).

## Structure
- `index.html`: Main UI dashboard (Profile, Fact Base, Verification & Evidence display).
- `app.js`: API client logic communicating with backend `/facts` and other endpoints.
- `styles.css`: Clean, ATS-safe styling.
