# CareerPR
AI Career Adaptation Platform — evidence-based career workspace that finds roles beyond the current job title, discovers transferable skills and honestly shows fit and gaps: vacancy → verified, human-approved tailored resume + cover letter → immutable snapshot.
Status: scaffold, MVP-0 in progress. License: Apache-2.0.

Quick start: `make setup && make dev` (see `docs/DEVELOPMENT.md`). AI contributors: read `AGENTS.md`.

Flow / Как работать: `docs/WORKFLOW.md` (RU+EN). Tasks / Задачи: `tasks/README.md`.
Product architecture review and recommendations: `docs/PRODUCT_ARCHITECTURE_REVIEW.md`.
